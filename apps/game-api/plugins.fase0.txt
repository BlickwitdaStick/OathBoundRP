# Phase 0 reference load order — SkyMP Heavy RP
#
# Exactly the five base-game masters. Nothing else.
#
# This is not an aesthetic choice: it is what the SERVER loads. Both Phase 0
# scripts pin this same list —
#   scripts/phase0/Install-SkyMPServerArtifact.ps1 (settings.loadOrder)
#   scripts/phase0/Prepare-SkyMPDataDir.ps1        ($masters)
# — so the server only knows the records from these five.
#
# A client with an extra plugin takes a load-order index the server does not
# have, and the first byte of every FormID is that index
# (docs/technical/MODS_AND_GAMEMODE_CONTRACT.md section 3). The `base_id` stored
# in the database would then point to a different record on that player's
# screen — no error, no log: a chest with something else inside.
#
# ALL testers need this list, exactly in this order, with nothing enabled
# beyond it. That includes Creation Club, _ResourcePack.esl and USSEP: useful
# on a real server, irrelevant for validating the gamemode, and each one
# shifts the order.
#
# Once the official modpack is assembled, this list goes away and the manifest
# is generated from the modpack, without `--only-load-order`.

*Skyrim.esm
*Update.esm
*Dawnguard.esm
*HearthFires.esm
*Dragonborn.esm
